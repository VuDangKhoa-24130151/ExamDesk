# Đóng gói — công việc về sau của Bạn 1

Hiện chỉ có khung WinForms, chưa có bộ cài hoặc script setup.
Sau khi luồng bắt buộc chạy đúng:
1. Publish Release cho Windows x64, self-contained.
2. Viết script Inno Setup, đưa thành phẩm publish vào bộ cài.
3. Thử cài/chạy/gỡ trên máy Windows khác và kiểm tra quyền ghi SQLite.

Không cần hoàn thiện đóng gói ở mốc khung sườn.
